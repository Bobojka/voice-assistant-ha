# Voice Assistant HA

Голосовий агент для Home Assistant: розуміє довільні українські фрази і виконує **скрипти з міткою «Голос»**.
Розпізнавання й розуміння робить сервіс [voice-assistant](https://github.com/Bobojka/voice-assistant)
(`transcribe-nlp`), а виконує все Home Assistant.

## Як це працює

1. Агент збирає каталог команд: усі скрипти з міткою «Голос» (назва, опис, поля).
2. Фраза і каталог ідуть у сервіс (`POST /v1/match`), він повертає, які скрипти попросили і з якими полями.
3. Агент запускає скрипти й озвучує їхню відповідь.
4. Нічого не знайдено або сервіс недоступний → фраза йде в запасний агент (вбудований агент HA),
   тож «увімкни світло на кухні» працює як раніше.

**Діалог.** Агент перепитує, коли бракує обов'язкового поля («Списати продукт: уточніть, продукт?») або
коли модель не впевнена («Виконати «Списати продукт»: Продукт: Молоко?» → «так» / «ні»).
Сателіт після питання слухає далі без слова-тригера.

## Універсальні команди для пристроїв

Скрипт на кожен пристрій не потрібен. Агент сам додає в каталог чотири команди для всіх сутностей,
**відкритих для Assist** (Налаштування → Голосові асистенти → вкладка «Відкрити доступ»):

| Команда | Приклади |
|---|---|
| увімкнути / вимкнути / перемкнути | «увімкни кондиціонер», «вимкни все світло на кухні», «закрий штори в спальні» |
| задати рівень | «постав кондиціонер на 23», «яскравість у вітальні 40», «гучність телевізора 20» |
| стан | «чи увімкнений кондиціонер», «яка температура в спальні», «чи спить Влад», «коли відключення», «яка погода» |
| запустити сцену чи скрипт | «увімкни режим кіно» |

Пристрій називається так, як у HA (ім'я або псевдоніми сутності); кімната — з області пристрою.
Групи: світло, розетки й перемикачі, кондиціонери й обігрівачі, штори й ворота, вентилятори, медіа,
пилосос, зволожувачі, усе. Пилосос: «увімкни» — прибирати, «вимкни» — на базу. Зволожувач: рівень — це
вологість у %. Стан відповідається по-людськи: датчики так/ні («є електрика»), час — «завтра о 9:30»,
погода — українською з температурою.
Вимкнути — параметр «Універсальні команди» в налаштуваннях інтеграції.

## Встановлення

1. HACS → ⋮ → Custom repositories → `https://github.com/Bobojka/voice-assistant-ha`, тип **Integration**.
2. Завантажити, перезапустити Home Assistant.
3. Налаштування → Пристрої та служби → Додати інтеграцію → **Voice Assistant HA**:
   адреса сервісу (наприклад, `http://192.168.88.100:8300`) і його токен (`KITCHEN_VOICE_TOKEN`).
4. Налаштування → Голосові асистенти → асистент → **Агент розмови: Voice Assistant**.
5. Там само **Перетворення мови в текст: Voice Assistant HA STT**. Це той самий сервіс, що й
   Wyoming STT, але в кожен запит додаються підказки для Whisper: кімнати, назви відкритих
   для Assist пристроїв і їхні аліаси, назви скриптів із міткою. Тому «кондиціонер» чується як
   «кондиціонер». Підказки видно в debug-лозі інтеграції.

**Параметри** (Налаштувати на картці інтеграції): мітка скриптів (за замовчуванням «Голос»), ім'я
асистента, поріг упевненості для перепитування (0.6), запасний агент (`conversation.home_assistant`,
`none` — вимкнути).

## Telegram

Ті самі команди текстом або голосовими в Telegram, без wake word, відповідь текстом.

1. У [tg-proxy](https://github.com/Bobojka/tg-proxy) створити підписника для потрібного бота, режим **poll**.
   Можна і напряму з Telegram: адреса `https://api.telegram.org`, токен бота (тоді цей бот більше
   ні для чого не використовується).
2. Параметри інтеграції:
   - **адреса Bot API**: `http://<сервер>:8310` (tg-proxy);
   - **токен**: внутрішній токен підписника;
   - **хто може давати команди**, по рядку: `983470091 = person.dima`.
3. Коли асистент перепитує, варіанти відповіді приходять кнопками («Так» / «Ні», пристрої,
   значення зі списку); натиснути кнопку — те саме, що написати відповідь. Кнопки відповідають
   лише тому, кого спитали.
4. Повідомлення від інших людей і команди на кшталт `/komora ...` асистент ігнорує. Якщо нічого
   не розпізнав, він мовчить, щоб не заважати іншим сервісам того самого бота.

Команда виконується від імені цієї людини (`user_id` її person), тож у журналі HA видно, хто що
ввімкнув. Голосові конвертуються вбудованим ffmpeg і розпізнаються з тими самими підказками, що й
голос із сателіта. У відповіді спершу видно, що почуто: `🎙 увімкни кондиціонер`.

## Продовження розмови

Після виконаної команди сателіт ще кілька секунд слухає без слова-тригера: «Окей Набу, увімкни
кондиціонер» → «і постав 22» → «дякую». Попередня команда йде в сервіс як контекст, тож короткі
доповнення розуміються. Тиша, «все», «стоп», «ні» — тихо завершують; «дякую» — «Будь ласка.».
Якщо наступна фраза не схожа на команду (говорять поруч, телевізор), асистент мовчки засинає.
Вимикається в параметрах. Працює для сателітів; у Telegram розмова і так безперервна.

## Гучність відповіді

Відповідь на сателіті звучить так само гучно, як прозвучав запит: гучно в шумній кухні, тихо
вночі. Розпізнавання міряє рівень голосу і шуму (dBFS) кожного запиту, а агент перед відповіддю
ставить гучність медіаплеєра того пристрою, з якого прийшла команда.

- Датчики **рівень голосу** і **рівень шуму** показують останній запит: скажи щось тихо, потім
  гучно і подивись, які числа виходять у твоїй кімнаті.
- Параметри: увімкнути/вимкнути, найтихіша і найгучніша відповідь, «тихий» і «гучний» запит
  у dBFS (за замовчуванням −45 і −20). Між ними гучність змінюється рівномірно. Шумно навколо —
  теж гучно: шум на 10 дБ нижчий за «гучний» поріг уже дає найгучнішу відповідь.
- Працює лише для сателітів з медіаплеєром і лише з «Voice Assistant HA STT» у пайплайні.

## Скрипт як голосова команда

```yaml
spysaty_produkt:
  alias: Списати продукт
  description: >-
    Щось витратили, взяли чи з'їли під час готування.
    Приклади: взяла двісті грам борошна; трохи кориці кинула в тісто
  fields:
    product:
      name: Продукт
      required: true
      selector: { text: {} }
    amount:
      name: Кількість
      description: "Скільки, числом: пів -> 0.5"
      selector: { number: { min: 0, max: 100000, step: any } }
    unit:
      name: Одиниця
      selector: { select: { options: [g, kg, ml, l, pcs, pack] } }
  sequence:
    - action: notify.smart   # або дія komora_ha, світло, сцена...
      data: { message: "Списано {{ product }} {{ amount | default('') }} {{ unit | default('') }}" }
    - variables:
        reply: { speech: "Записала: {{ product }}." }
    - stop: done
      response_variable: reply
```

Скрипту треба додати мітку **«Голос»**.

| Скрипт | Для сервісу |
|---|---|
| ключ скрипту (`spysaty_produkt`) | назва команди |
| `alias` + `description` | опис; рядок «Приклади: а; б» — приклади фраз |
| `fields` | поля команди; `required` — обов'язкові (агент перепитає) |
| `selector: number` / `boolean` / `text` | число / так-ні / текст |
| `selector: select` з `options` | вибір зі списку |

**Відповідь скрипту** (`stop` з `response_variable`), усе необов'язкове:
- `speech` — що сказати (без нього агент скаже «Готово: <назва>.»);
- `continue_conversation: true` — після відповіді слухати далі без слова-тригера (скрипт поставив питання);
- `context` — що передати сервісу разом із наступною фразою, щоб він зрозумів коротку відповідь;
- `options` — список варіантів відповіді (до 10), у Telegram вони стануть кнопками.
